## What it is

An app on the proven **resonance-echoes body** that presents this house's strictly
informational repos as a place people can *learn* in — pretty, and cosmically
presentable. **One body, many corpora**, which is the spring's own law: *suites are
not built, they are combined.*

## Why this is the cheapest app the house can build

- **Static content.** No domain schema to rule first, no device permissions, no
  recorder, no audio. Sistrum needed a domain ruling before a line of it was safe;
  this needs none.
- **The body is proven** — sixth house down the echoes road, and each one has stood up
  faster than the one before.
- **The cosmic tokens now feed a new app from birth.** As of 2026-08-12 the
  distribution manifest carries 13 consumers instead of 7, so a new app is no longer
  a hand-carry that silently drifts. *That fix landed the same afternoon as this idea,
  by accident of order.*
- **`adapter-static` already produces a deployable site**, and the Vercel account is
  Pro (`resonance-chamber/constellation/opus/lanes/integrations/KEYS-MAP.md`,
  amended by KP's own hand 2026-07-31).

## The feeling log — and it is not a comment box

KP's law, spoken the same day about a different app and true here:

> *"logging how we feel during a moment is the base of all we do, self understanding
> and understanding oportunities abound"* · *"it is how we discover our values and
> internal core interests, which help us align with ourselves"* ·
> *"humans and tech need this as money becomes irrelevent"*

So the mechanism is **the one this family already has**, not a new invention: a feeling
carries `sense · subcategory · emoji · intensity · note · timestamp`, and it hangs on
the thing it is about — here a paper, or a section of one.

**And for a feeling pinned to a POSITION inside a text, `the-moment-marks` already
exists** — built 2026-08-01, 29 printing proofs, append-only by law, emoji-first, each
mark carrying *the marker's own private definition* of that emoji. Its own README
already says it is "the mood-event logging shape on a timeline." A paragraph anchor is
a different addressing scheme than a second of audio; **the marks model pins to a
timeline, so text anchoring is the one genuinely open technical question** in this
whole note.

## Sharing: opt-in — and the primitive exists with the correct default already chosen

KP's law from the same day: **opt-in always, "no force or deceptive theft."**

- **`the-moment-marks`** `shareDoc()`: *"moments, emoji, and chosen names travel;
  private definitions and notes stay home unless the sharer explicitly says
  `--keep-contents`. The local path never travels."* **The safe default is already the
  built default.** Nothing needs to be talked into behaving.
- **`the-envelope`**: versioned, app-namespaced, **counts written on the outside** so a
  person can see at a glance that the file carries what the screen showed; import
  non-destructive by law.

So "share it with us should they choose" is: **the reader's own act produces a sealed
envelope carrying structure, and their private words stay home unless they say
otherwise.**

## The open question that is KP's, not a builder's

**Where does a shared feeling LAND?**

This house has deliberately built **no outward-speech tools**. The Bridge's Resend line
has **no send tool** — *"a send is a consent gate."* The Discord line has **no post
tool** — *"a post is outward speech."* Both were refusals on purpose, at the
experts' own commissions.

**So a receiving channel is a new decision, not an existing capability.** Named here
without choosing, because choosing is his:

- the reader downloads an envelope and sends it however they like (**zero new
  infrastructure, zero new surface, and nothing to breach**)
- a Supabase table with RLS and a public-insert policy (a write door the house does not
  currently have anywhere)
- an email address, an issue, a form

The first option is the only one that needs nothing built and breaks no existing ward.
**It is also the slowest to gather anything**, and that trade is the actual decision.

## The stakes that are new here, and they are the reason to go slowly

**This is the first surface in the Sanctuary where the person logging a feeling is not
KP.** Every repo in this house carries a badge that reads **data collected: none**. That
is not a preference to be revisited when convenient; it is a published promise, and
local-by-default is what keeps it true.

Any receiving channel therefore needs, before a line of it exists: what is stored, for
how long, whether it can be withdrawn, and who can read it. *Consent gates every door.*

## ADDENDUM, the same hour — **this is already built, twice**

*At KP's ⚛ word: "our gaia and awen apps are just informational right now" · "just
showing our docs." Measured immediately after, because it changes the whole shape of
the idea and my first reading above was written without it.*

**`resonance-gaia` and `resonance-awen` are already exactly the app this note
describes** — echoes bodies whose current job is presenting documents. Both carry
`src/routes/docs/+page.svelte` (~6.7 KB), and gaia carries a `schema/` surface beside
it. **Papers would be the third instance, not the first.**

**And their docs page is not hand-authored prose — it is a real markdown pipeline:**

```
import readme    from '../../../README.md?raw';
import checklist from '../../../docs/CHECKLIST.md?raw';
import { renderMarkdown } from '$lib/markdown';
const rendered = $derived(renderMarkdown(worn.text));
{@html rendered}
```

Vite's `?raw` pulls the repo's **own** markdown at build time, `$lib/markdown` renders
it, and a picker wears one document at a time. **There is nothing to invent here.** The
corpus in this repo — three papers, the glossary, the attestations — drops into that
shape as it stands.

**The feeling log is also already adapted for this class of app.** `add/`, `insights/`,
`sattva/` and `timer/` in gaia and awen are **byte-identical to each other and
different from echoes'** — so an informational-app variant of the feeling machinery
already exists and is already shared by two apps. *"Let people log their feeling about
what we are doing" is closer to a join than to a build* — which is this line's own
standing law: when something looks missing here, assume it exists and is unwired.

### The one genuinely new decision this idea introduces — and it is a security seam

There are **two** markdown renderers in the house, and the difference stops being
academic the moment a stranger types:

- **`$lib/markdown` + `{@html}`** — what gaia and awen use. Its own page comment states
  the trust argument plainly: *"realm's own papers, so the html below is ours end to
  end."* Sound, **because the input is the house's.**
- **`the-scrolls`** (built 2026-08-06, one file, zero imports, headless renderer
  importable in node) — **escape-first by law**: *"authored text can never smuggle
  markup; the subset is applied to escaped text"*, and the subset is five named forms
  because *"a scroll is a calm reader, not a browser."*

> **The house's own papers may keep the existing renderer. Anything a READER writes —
> a feeling's note, a shared definition — must go through the escape-first law.** The
> moment the input stops being ours, the trust argument that justifies `{@html}` stops
> being true. That is the whole of it, and it costs nothing to get right at the start
> and a great deal to retrofit.

*(`the-scrolls`' own README already names the next step as a consumer's combination for
a later sitting: "a mapped scroll unrolling its own file... the vigil would watch, the
scroll would show.")*
